# Python Fundamentals Projects 🐍

## Projects Overview

### 1. Algorithms with IMDB
Exploring data processing and sorting techniques using the IMDB movie dataset.

### 2. Arithmetic Exam Application
A console application designed to generate math problems and track student performance.

### 3. Chatbot with Python
A basic conversational agent demonstrating string manipulation and conditional logic.

### 4. Coffee Machine
A simulation of a coffee machine's internal state, managing resources (water, milk, coffee) and transactions.

### 5. Currency Converter
A tool for real-time currency exchange calculations utilizing external data.

### 6. Duskers
A text-based strategy game involving drone command logic and survival mechanics.

### 7. Simple Tic-Tac-Toe
Implementation of the classic game with grid management and win-condition validation.

### 8. University Admission Procedure
A data-processing script for managing student applications and ranking candidates based on exam results.

### 9. Easy Rider Bus Company
Validating JSON data from documentation using regular expressions, sets operations (intersection, difference) and the itertools module.

### 10. File Manager
Implemented commads like cp, mv, rm, ls etc. with os and shutil module(unfinished).

**Objective:** Mastering Python logic, Object-Oriented Programming (OOP), and data handling.
